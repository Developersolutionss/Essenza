# Concepto del sistema

## Qué es Essenza

Essenza genera audios con voz clonada.
La voz clonada pertenece a una modelo de OnlyFans.
La chatters envían estos audios a los fans.
El audio suena como la modelo real.

## Actores

El sistema tiene tres actores:

- **Admin**: el dueño de la plataforma. Administra todo.
- **Manager de agencia**: administra modelos y chatters. Ve el uso y los costos.
- **Chatter**: atiende la cuenta de una modelo. Genera los audios.

## Conceptos clave

Una **modelo** es un perfil de OnlyFans.
Una modelo tiene una o varias **voces** clonadas en ElevenLabs.
Una **chatter** trabaja para una agencia. Genera audios para una o varias modelos.

## Control de acceso

Cada chatter solo usa las voces de las modelos asignadas.
El admin o el manager asigna modelos a cada chatter.
La chatter no ve las voces de otras modelos.

## Flujo principal

1. La chatter escribe un texto.
2. La chatter selecciona una voz de una modelo asignada.
3. El sistema genera el audio con texto a voz.
4. La chatter descarga el audio o lo envía al fan.

## Reglas de negocio

- Una modelo debe tener consentimiento firmado para generar audio.
- El uso de voz se mide por caracteres.
- ElevenLabs cobra por caracteres.
- La chatter tiene un límite diario de caracteres.
